## 4. 数据接入与迁移

| 数据 | 来源 | 接入方式 | 校验/幂等 | 回滚 |
| --- | --- | --- | --- | --- |
| 成员 | 管理员录入 | Web/API | 邮箱唯一、最后管理员保护 | 停用而非删除 |
| 内容任务 | 运营表单/自动化 | API + Queue | operationId 唯一 | 取消未执行部分/回收站 |
| 附件/图片 | 上传、粘贴、AI、GeekHome | Asset API | MIME、大小、归属、签名 | 删除资产；外部副本按运维策略 |
| 渠道账号 | 扩展读取公开身份 | 扩展 API | 连接+平台唯一，执行前复核 | 停用绑定 |
| 公众号结尾 | 管理员配置 | app_settings | Schema 校验；任务快照 | 恢复上个配置需 V1.4 版本能力 |
| 定时计划 | 管理员配置 | Scheduler | schedule/occurrence 唯一 | 停用/删除调度源 |

正式导入不得通过修改演示 Seed 完成；生产数据迁移需要预检、备份、幂等和错误报告。

## 5. 品牌与视觉档案

- 产品名称：极客跳动 AI 运营中心；英文品牌：GeekDance（无空格）。
- 使用场景：内部运营后台，Operate，风险 L2（全平台原型重建，但不改变现有品牌世界）。
- 视觉关键词：专业、克制、高效、可信、品牌一致。
- 颜色：极客跳动红 `#E60012/#DA251C` 为行动与强调色；黑 `#17171A`；白；冷中性灰背景。
- 字体：后台使用可读中文无衬线；程序生成图片必须使用 Alibaba PuHuiTi 2.0（85 Bold / 55 Regular）。
- 视觉签名：左侧黑色 AI 工作区块 + 克制红色当前状态线；编辑与预览使用“白色稿纸”而非卡片堆叠。
- 反例：紫蓝 AI 渐变、发光玻璃、每个字段一张卡、无意义大指标、无法解释的横向滚动、白底贴片 Logo。
- 响应式：桌面 1440px；移动 390px。桌面侧栏，移动顶部水平导航；移动主操作 ≥44px。
- 无障碍：正文对比度 ≥4.5:1；焦点可见；表单错误就近；弹窗焦点可恢复。

## 6. 默认内容清理清单

| 检查项 | 结论 |
| --- | --- |
| 演示品牌/无关菜单 | LinkedIn 不再作为预留或“即将上线”，进入正式渠道能力 |
| 演示指标 | 工作台使用真实数据库指标；禁止恢复 AI 成本/伪成功率卡片 |
| 默认账号/密码 | Bootstrap 仅从环境变量注入，首次强制改密；文档不得写真实值 |
| 明文密钥 | 只在环境变量；数据库和日志不保存 |
| Mock | 只用于本地回归，页面/报告不得宣称生产可用 |
| Seed 自动化 | 预置计划默认 disabled |
| `.env.example` | 已存在根示例；不得提交真实 `.env` |
| 发布边界 | 官网/公众号保持草稿；五个浏览器渠道支持草稿和受控正式发布，强门禁不可关闭 |

## 7. 适配影响与实施顺序

1. 先锁定产品、权限、对象状态和七渠道边界。
2. 再统一内容生产、人工复核、图片与渠道结果的契约。
3. 随后完成扩展、多账号、自动化和管理页适配。
4. 最后执行桌面/移动原型核对、自动化回归和真实账号验收。
