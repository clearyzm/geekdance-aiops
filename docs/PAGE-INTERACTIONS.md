# 极客跳动 AI 运营中心｜页面交互文档

- 版本：I1-V1.3-draft
- PRD：V1.3.2-draft
- 覆盖端：运营中心 Web（桌面 1440px、移动 390px）+ Chrome 扩展弹窗/创作页协作
- 更新时间：2026-08-18
- 状态：全平台交互基线草稿，待用户 Review
- 原型策略：20 个关键高保真 Frame 覆盖主闭环与代表性状态；其余 Loading、Empty、Error、NoPermission、Disabled、Confirm 和 Success 状态以本交互文档及覆盖地图约束，不宣称均有独立高保真 Frame。

## 1. 视觉简报

- Surface：内部 Operate；本轮为全平台原型重建，L2。
- 受众：高频运营成员、低频管理员；用户目标是快速完成任务而非浏览营销内容。
- 关键词：专业、克制、高效、可信、品牌一致。
- 色彩：白色内容面、冷灰页面背景、黑色关键文本、极客跳动红仅用于主操作/选中/风险状态。
- 字体：后台使用统一中文无衬线；内容预览继承各渠道排版；图片成图使用阿里巴巴普惠体。
- 密度：列表中高密度、创建表单中密度、复核编辑器高内容密度；避免每行都用圆角卡片。
- 视觉签名：左侧黑色 AI 工作区块、当前导航红色状态线、连续白色稿纸编辑区。
- 图标：Lucide 统一线性图标，不用 Emoji/Unicode 代替图标。
- 动效：150–250ms，仅用于菜单、切换、加载和成功反馈；不做页面入场表演。
- 无障碍：4.5:1 正文对比度、可见焦点、44px 移动点击区、错误就近、Dialog 焦点闭环。
- 反例：紫蓝渐变、玻璃发光、英雄数字模板、嵌套卡片、空白大面积撑高、根横向滚动。

### 1.1 全局壳层

- 桌面：248px 固定左侧栏；82px 顶栏；主内容自适应。导航按 PRD 顺序，管理员菜单根据角色显示。
- 移动：顶部 Logo + 账号菜单，下方水平可滚动导航；只允许导航容器横向滚动，页面根不滚动。
- 账号菜单：姓名、邮箱、角色、账号与安全、退出。退出弹出浏览器/设计系统确认，说明未提交内容影响。
- 全局状态：401 跳登录；428 强制改密；403 显示无权限；网络错误保留页面并提供重试。
- Toast 只用于跨模块成功；表单错误、上传错误和任务错误必须就近显示。

## 3. 逐Frame定义

### PAGE-AUTH-001 登录

- 目标：识别成员并进入工作区。
- 模块：左侧品牌与能力说明；右侧登录表单；邮箱、密码、登录按钮、安全说明。
- 校验：邮箱格式；密码非空；提交 Loading 防重复。
- 错误：账号/密码错误统一文案；锁定不泄露账号存在性；网络错误可重试。
- 成功：`mustChangePassword=true` 进入强制改密，否则工作台。
- 移动：单列，品牌说明压缩但 Logo 和产品名保留。

### PAGE-AUTH-002 首次改密

- 前置：服务端返回 428 或用户标记强制改密。
- 字段：当前密码、新密码、确认新密码；新密码至少 12 位。
- 成功：清理旧会话、创建新会话、进入工作台。
- 取消：只允许退出，不允许绕过进入业务页面。

### PAGE-DASH-001 工作台

- 模块顺序：问候与创建 CTA → 四项真实指标 → 最近任务 → 渠道健康 → 快捷操作/自动化摘要。
- 指标：今日任务、待复核、自动化启用/总数、可用渠道/7。
- 渠道健康：官网、公众号、五个扩展渠道；每项展示 live/degraded/not_configured 及原因。
- 降级状态：保留可用模块，异常渠道显示“查看渠道管理”。
- 空状态：最近任务引导创建内容；无自动化只对管理员显示创建入口。

### PAGE-CONTENT-001 创建内容

- 页面结构：左侧主表单，右侧自动流程与“先复核”安全说明。
- 字段顺序：内容类型 → 案例状态/图类型（条件）→ 主题 → 附件 → 参考链接 → 标签 → 标题与候选 → 读者模式/图片策略 → 补充要求 → 七渠道 → 提交。
- 通识：七渠道可多选；AI 结构插图默认，GeekHome 可选。
- 案例：仅小红书；必须有附件、案例状态、封面 + 至少一类项目图。
- 候选标题：点击后局部 Loading，显示 12 条可滚动候选；选中后可继续编辑；输入变化使旧候选失效。
- 标题限制：根据已选渠道实时显示最严格长度、当前字符数和超限错误。
- 附件：选择/粘贴；逐项大小、上传、删除；页面离开前若有未提交输入给出提醒。
- 默认指令：读取个人值；编辑不自动覆盖默认；“保存为我的默认指令”有 Loading/成功/失败。
- 提交：先上传附件，再创建任务；成功进入任务详情；429 显示活动任务上限并链接任务中心。

### PAGE-TASK-001 任务中心

- 模块：标题/搜索/回收站入口 → 任务列表。
- 行/卡片字段：标题、主题、任务 ID、创建人、创建时间、整体状态、进度、七渠道状态。
- 操作：打开详情、移入回收站；删除中仅该项 Loading。
- 搜索：标题、主题、ID；无结果区别于无任务。
- Error：保留搜索和刷新；不显示伪空态。

### PAGE-TASK-002 任务详情与复核

- 顶部：标题、任务 ID、创建人、整体状态、删除/取消/重试（按状态显示）。
- 创建输入：默认展开，完整显示内容类型、主题、标题、读者、策略、渠道、标签、要求、链接、附件和案例配置。
- 生成中：阶段时间轴、百分比、当前消息；轮询不覆盖手动选择。
- 内容复核桌面布局：左 68% 连续编辑器；右 32% 预览/智能配图切换。证据和渠道结果放页面下方，避免拉长一侧形成空白。
- 编辑器：同一白色稿纸；标题、摘要、开场、章节、观察、总结、CTA 自适应高度；Enter 真换行。
- 渠道标签：切换同步编辑器、预览、智能配图和提交决定。
- 图片锚点：聚焦段落选中插入点；候选图插入当前点；图片支持放大、裁剪、替换、删除。
- 智能配图：全部/AI/GeekHome/上传筛选不改变左侧布局；候选保持 4:3 或真实比例；上传只入候选池。
- 预览：官网桌面、公众号手机、小红书/浏览器渠道预览标签；图片可灯箱放大。
- “预览当前修改”：保存当前复核稿并重建真实 HTML；按钮显示 Loading，成功刷新 iframe，失败就近说明。
- 公众号封面：上传真实图后立即出现 2.35:1 和 1:1 可拖动裁剪选区、最终拼图和预览。
- 内容决定：通过前确认“仅创建当前渠道草稿”；驳回说明不会删除其他渠道草稿。
- 结果核对：显示外部草稿 ID/URL 可选项；确认已存在不调用平台；确认未创建并重试需二次确认。
- 只读完成态：文章、预览、复核历史、渠道草稿链接和错误证据保留。

### PAGE-REV-001 人工复核

- Tabs：待处理（默认）/已处理。
- 列表字段：标题、渠道、复核类别、原因、创建人、进入时间、状态、处理人/时间。
- 点击进入任务详情并自动定位对应渠道。
- 空：说明没有待处理项，提供任务中心入口；错误提供重试。

### PAGE-TRASH-001 回收站

- 说明：删除内部记录不删除外部草稿。
- 列表：标题、创建人、删除时间、原状态、恢复、永久删除。
- 永久删除：危险确认，明确无法恢复但外部草稿不受影响。

### PAGE-ASSET-001 内容资产

- 顶部：上传区（选择/拖放/粘贴）、搜索、来源/类型筛选。
- 资产网格：真实缩略图、名称、来源、尺寸/MIME、创建时间；操作等宽对齐。
- 重命名：原位固定高度输入；保存/取消图标，不放大卡片。
- 上传：每文件独立 Loading/成功/失败；失败说明大小、格式、iCloud 未下载、网络、服务端或存储原因。
- 图片点击灯箱；删除危险确认；空态引导上传或图片工坊。

### PAGE-STUDIO-001 图片工坊

- 左侧工具导航；主区根据工具显示输入、真实预览和参数；右/下方显示异步任务结果。
- 上传源素材支持选择/粘贴，素材卡写明用途；添加到内容资产显示 Loading。
- 人物融合：人物、背景两个明确槽位；要求可选；默认自动适配。
- Logo：底图、Logo 两槽；在真实预览拖动位置和宽度。
- 局部改字：上传 → 识别 Loading → 图上文字框 → 选择/微调 → 输入新文字 → 生成。
- 工具任务：提交禁重复；轮询百分比；成功显示下载/进入资产；失败显示错误码和重试。

### PAGE-WECHAT-001 公众号结尾

- 管理员：结构化编辑介绍、口号、电话、网站、地址、1–6 条服务、0–3 条精彩推荐；右侧手机预览。
- 运营：只读当前生效版本和生效说明。
- 校验：推荐必须 HTTPS；字符上限；保存 Loading/成功/失败。
- 说明：新任务保存快照，历史任务不跟随变化；不会触发群发。

### PAGE-CHANNEL-001 渠道管理

- 模块一“当前电脑”：扩展未安装/版本过旧/已安装未连接/已连接/过期；下载、检查、启用、停用。
- 模块二“五平台绑定”：小红书、知乎、今日头条、百家号、LinkedIn 的当前电脑账号、状态、最近在线和绑定动作。
- 模块三“七渠道健康”：运行开关、Worker/Release、接口/扩展问题和恢复建议。
- 模块四“团队平台账号”：平台、账号、成员、电脑、最近在线、状态；普通成员只停用本人，管理员可停用任意。
- 不展示：令牌、API 地址、Cookie、密码。

### PAGE-DIST-001 多账号发布

- 创建：选择已复核文章 → 浏览器渠道 → 多选账号 → 草稿/正式模式。
- 无文章：引导完成复核；无账号：引导渠道管理绑定。
- 正式模式：危险区展示文章、平台、账号；勾选已核对并输入完整标题；未满足按钮禁用。
- 提交：operationId 幂等；成功显示批次。
- 执行：每账号展示等待电脑、领取、上传、已填、保存/发布、成功、失败、结果不明。
- 结果：汇总状态与逐项证据；ambiguous 提示先去平台核对，不展示直接重试。

### PAGE-AUTO-001 定时任务（管理员）

- 列表：名称、每日时间、时区、渠道、启用、上次触发/结果；编辑、启停、立即运行、删除。
- 新建/编辑：内容模板字段与创建内容一致；七渠道可任意多选；默认停用；启用前健康检查。
- 立即运行：确认并显示已接受；只生成七渠道复核稿，运行结果进入任务中心，不直接创建外部草稿或正式发布。
- 复核后：官网/公众号进入服务端草稿，五个浏览器渠道生成扩展上传包；如需正式发布，转入多账号发布页面重新执行强确认。
- 删除：说明会删除未来调度，不删除已产生任务。

### PAGE-MEMBER-001 成员管理（管理员）

- 列表：姓名、邮箱、角色、状态、首次改密、创建时间。
- 新建：姓名、邮箱、角色、至少 12 位临时密码。
- 编辑：姓名、角色、启停、重置临时密码。
- 危险规则：停用会使会话失效；最后管理员操作返回明确错误。

### PAGE-SETTINGS-001 系统设置

- 全员：修改密码；账号与安全说明。
- 管理员：公众号结尾兼容入口、AI 模型与渠道配置只读摘要、安全基线。
- 密钥只显示“已配置/未配置”，不显示明文；运维配置不可在后台随意覆盖。

### EXT-001 扩展弹窗/创作页协作

- Ready：产品名“极客跳动多平台草稿助手”、版本 1.4.0、连接、当前任务阶段。
- Action Required：未连接、版本过旧、未登录、验证码、账号不符、页面结构变化、结果不明。
- 阶段：领取 → 下载图片 → 打开页面 → 上传填写 → 已填/保存 → 完成或人工核对。
- 小红书已填后提示人工点击暂存；话题使用平台真实话题组件并横向排列，正文不残留重复检索文字。
- LinkedIn 复用同一扩展领取、账号核对、图片下载、内容填写和结果回传框架；支持草稿与受控正式发布，无法唯一确认成功时进入人工核对。

## 7. Review记录

### 7.1 内容长度与响应式样例

- 最短：2 字主题、无可选标签、1 个渠道、0 个参考链接。
- 典型：30–60 字主题、2 个附件、3 个链接、3 个渠道、6 张插图。
- 最长：300 字主题、10 个附件、20 个链接、7 个渠道、120 字标题（仅允许渠道）、多段复核文本和多账号批次。
- 桌面：任务复核左右分栏；列表/表格优先保持列语义。
- 390px：所有页面单列；表格转卡片或横向滚动仅限表格容器；复核顺序为编辑器 → 预览 → 配图 → 证据/结果。
