## 阅读方式

1. 先查看 `gD0Tf.png` 理解设计令牌与布局规则。
2. 按工作台 → 内容生产 → 任务生成 → 内容复核 → 渠道结果阅读主闭环。
3. 再查看资产、图片工坊、公众号结尾、渠道、多账号和管理员能力。
4. 向下滚动完整 HTML 可查看新增的 28 个详细 Frame；也可使用 `?frame=<Frame ID>` 单独预览 1440×960 页面。
5. 以 `VJIsC.png` 和 `docs/PAGE-INTERACTIONS.md` 核对页面、对象状态及系统状态覆盖。

## 已确认的产品决策

- D-001：浏览器渠道正式发布长期保留，并维持人工复核、账号核对、指纹和二次确认门禁。
