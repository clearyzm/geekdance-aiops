# 极客跳动多平台草稿助手

这个 Manifest V3 扩展从极客跳动 AI 运营中心领取已经人工复核的内容，使用当前 Chrome 中已登录的账号写入小红书、知乎文章、今日头条图文、百家号图文和 LinkedIn 文章草稿。小红书保留原有“自动上传填写，人工点击暂存离开”流程；其他平台只在识别到唯一、明确的保存草稿按钮时自动保存。

## 同事安装与使用

1. 使用自己的运营中心账号打开“渠道管理”，下载公司版扩展 ZIP 并解压。
2. 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的 `geekdance-multi-platform-draft-uploader` 目录。
4. 在同一 Chrome 中登录需要使用的小红书、知乎、今日头条、百家号或 LinkedIn 创作后台。
5. 从运营中心的指定任务点击对应平台的“保存到草稿箱”。首次使用会自动完成当前电脑连接，不需要复制令牌或填写接口地址。

运营中心提示扩展有更新时，请点击“下载兼容更新包”，把压缩包中的文件覆盖到原 `geekdance-xiaohongshu-draft-uploader` 目录，再到扩展管理页点击“重新加载”；不要把新旧目录同时加载。当前版本为 `1.4.0`。原目录内更新会保留 Chrome 扩展 ID 和已有电脑连接，无需重新录入技术凭据。

每位运营同事都应在自己的电脑上独立安装，并使用自己的运营中心账号操作。网站会在后台为这台电脑建立独立连接；同事不需要查看或复制技术凭据。扩展使用该 Chrome 当前登录的小红书账号保存草稿，因此不同电脑、不同小红书账号不会交换密码或 Cookie。

扩展不提供“领取下一条团队任务”，只能执行运营成员在任务详情明确指定的渠道任务，避免把团队内容保存到错误账号。网站桥接脚本只在 `https://aiops.geekdance.cn` 和明确的本地开发地址运行；任何平台的密码与 Cookie 都不会传给运营中心。

本地验收时，从 `http://127.0.0.1:3000` 打开运营中心并在“渠道管理”完成连接，扩展会固定连接 `http://127.0.0.1:4000`。扩展仅额外允许 `127.0.0.1` 和 `localhost`，不使用 `<all_urls>`。

## 安全边界

- 不保存、上传或读取任何平台的密码和 Cookie。
- 不调用各平台非公开发布接口。
- 小红书不自动点击“暂存离开”；其他平台只允许点击唯一且文字精确匹配的草稿按钮。
- 禁止点击“发布”、“立即发布”、“提交审核”等正式对外操作。
- 遇到验证码、编辑器结构不唯一或草稿成功信号缺失时安全停止。
- 执行中断且无法确认结果时回传 `ambiguous`，服务端不会自动重试。
- 电脑连接可在渠道管理停用，90 天过期；底层授权信息不会在运营界面展示。

## 平台改版维护

五个创作平台的页面结构都可能变化。小红书选择器集中在 `site-adapter.js`，知乎、今日头条、百家号和 LinkedIn 集中在 `article-site-adapter.js`。每个平台首次生产验收必须在已登录真实账号中核对标题、正文、图片、草稿按钮和成功提示；不得通过放宽唯一性检查或加入坐标点击来“修复”适配。
